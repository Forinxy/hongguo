## 功能

- 隐藏状态栏 / 顶部控件（可独立开关）
- 隐藏播放器工具栏、底部小白条、视频进度条
- 拦截广告 / 挂件 / 片尾广告 / 暂停广告
- 禁用下拉刷新
- 顶部区域拦截下滑
- 解锁 VIP、显示 VIP 图标
- 暂停后恢复控件
